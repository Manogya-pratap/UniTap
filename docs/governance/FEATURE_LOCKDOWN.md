# 6️⃣ PHASE-1 FEATURE LOCKDOWN CHARTER

*(How you avoid killing yourself early)*

## 🎯 Purpose
Protect focus, stability, and trust.

---

## ✅ Phase-1 INCLUDED FEATURES
* Student app (wallet view, attendance view)
* Attendance (NFC card)
* College admin dashboard
* Basic reports
* UPI payments
* Card block/unblock
* **QR Code generation for identification/attendance fallback**

---

## ❌ Phase-1 EXCLUDED FEATURES
🚫 Metro integration
🚫 Apple Wallet claims
🚫 Offline wallet debit
🚫 AI fraud scoring
🚫 Public APIs
🚫 Multi-country support
🚫 **Off-campus QR Code payments (Reserved for Phase 3)**

---

## 🧱 Sales Guardrail
> “If a feature is not in Phase-1 charter, it cannot be promised.”

---

## 🧠 Why This Is Critical
Most startups fail by:
* saying yes too early
* overloading engineering
* breaking trust
This document **protects the company**.
