# 3️⃣ GOVERNANCE & OVERRIDE POLICY

*(Handling human misuse & power abuse)*

## 🎯 Purpose
Prevent **internal fraud**, **academic misuse**, and **authority abuse**.

---

## 🧠 Override Types

### A. Attendance Override
* Missed class
* Medical leave
* Device failure

### B. Wallet Override
* Refund approval
* Charge reversal
* Temporary unblock

### C. Access Override
* Late hostel entry
* Visitor exception

---

## 🔐 Override Rules (STRICT)

| Rule         | Requirement      |
| ------------ | ---------------- |
| Dual control | 2 roles required |
| Time-limited | Auto-expiry      |
| Logged       | Immutable audit  |
| Visible      | User notified    |

---

## 🧾 Example Attendance Override Flow
```
Teacher Request → Admin Review → Approval → Audit Log → Parent Notification
```
No silent changes allowed.

---

## 🚫 Forbidden Actions
❌ Bulk attendance without logs
❌ Wallet credit without ledger entry
❌ Device bypass
❌ Retroactive edits without reason
